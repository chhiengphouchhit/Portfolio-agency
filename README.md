# Portfolio-agency 🚀

A modern, high-converting Portfolio Website Creation Service & Template Marketplace built with React, Vite, and Tailwind CSS.

## ✨ Features
- 🌟 **25 Real Portfolio Templates** across 5 Industries (Designers, Developers, Photographers, Business/Pro, Bento & Minimal CVs)
- 👁️ **Full Working Interactive View** with Desktop & Mobile Frame Switcher
- 🎨 **Creative Motion Graphics** (Aurora glow, floating 3D badges, infinite running kinetic tickers)
- 💬 **1-Click Telegram Direct Order** with pre-filled template message
- 🌐 **Dual Language Support** (ភាសាខ្មែរ & English)
- 🌙 **Dark & Light Mode** Theme Support

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Custom Glassmorphism & Keyframes
- **Icons:** Lucide React
- **Deployment:** GitHub Pages / Vercel / Netlify

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
